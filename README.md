# ClockIN - WebApp

ClockIN é uma aplicação web simples para registro de ponto eletrônico.

O projeto foi desenvolvido com PHP, HTML, CSS, JavaScript e MySQL, utilizando XAMPP como ambiente local.

## Funcionalidades

- Login de usuários
- Área de administrador
- Cadastro de colaboradores
- Pesquisa de colaboradores
- Registro de ponto com data e hora
- Captura de localização
- Captura de foto no momento do registro
- Histórico de registros
- Visualização da localização no Google Maps
- Paginação dos registros

## Tecnologias utilizadas

- PHP
- HTML
- CSS
- JavaScript
- MySQL / MariaDB
- phpMyAdmin
- XAMPP
